# Devine helper scripts

`devine` forwards shell commands to the compatible runtime. `start-devine.sh` starts the customized shell and optional user services. `desktop-action.py`, `desktop-control.py`, `move-window.py`, `screenshot.py`, `sync-theme.py`, and `themed-swash.py` provide the custom desktop integrations.

The shell expects this directory to be installed at `$XDG_DATA_HOME/devine/scripts` (normally `~/.local/share/devine/scripts`) by `install.sh`.
