# Devine command line tools

Devine's command line tools provide shell, wallpaper, theme, recording, screenshot, clipboard, emoji, and window-resize commands. They are adapted from Caelestia CLI under GPL-3.0-only. See `UPSTREAM-LICENSE` and the project `NOTICE.md`.
